# ارشيف مقالات وكتابات الانبا مكسيموس

موقع ثابت عام يضم 605 وثائق و661 قسمًا من المكتبة المعتمدة. توجد 525 مقالة و77 محاضرة و3 كتب. كل كتاب له فهرس وصفحة لكل قسم. يحتوي المشروع على النصوص المنسّقة وبيانات العرض فقط. فهرس Pagefind وجميع نصوصه متاحة للعامة.

يشمل المشروع بوابة رمز زيارة شكلية، وفهرس AI ونصوص TXT عامة، وتوجيه noindex لكل HTML. راجع [بوابة الزيارة وسياسة الفهرسة](ACCESS-AND-INDEXING.md) للتفاصيل وحدود منع الفهرسة على GitHub Pages. يمكن متابعة نتيجة نشر كل إصدار من صفحة Actions.

## المعاينة على جهازك

يتطلب البناء Node.js 24.

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd test
npm.cmd run test:browser
npm.cmd run preview
```

افتح http://127.0.0.1:8090/ لمعاينة الموقع. يستخدم اختبار المتصفح Chrome أو Chromium المثبت على جهازك. يمكن تحديد مساره بمتغير البيئة CHROME_PATH.

الملفات الجاهزة للاستضافة داخل dist. يتحقق أمر البناء من HTML الآمن، وينشئ الصفحات والفهرس من جديد عند كل تعديل. يحدد SITE_BASE مسار مستودع GitHub Pages تلقائيًا في سير العمل، ويُستخدم المسار / للمعاينة المحلية.

## الموقع المنشور والتحديث المجاني

- الموقع: [الأرشيف](https://bond86.github.io/written-library-public/).
- المستودع العام: [Bond86/written-library-public](https://github.com/Bond86/written-library-public).
- متابعة النشر: [GitHub Actions](https://github.com/Bond86/written-library-public/actions).

تم تفعيل **Settings → Pages → Source → GitHub Actions**. كل تعديل على main يعيد البناء والفهرسة والاختبار والنشر تلقائيًا. عند فشل الاختبارات لا تُنشر النسخة الجديدة، وتظل آخر نسخة منشورة متاحة. لا تحتاج إلى إنشاء المستودع أو تهيئة Git مرة أخرى. استخدم **Actions → Build and publish written library → Run workflow** لإعادة تشغيل النشر عند الحاجة.

تتوفر GitHub Pages للمستودعات العامة على GitHub Free، ويستخدم المشروع مشغل ubuntu-latest القياسي المجاني للمستودعات العامة. لا يتطلب الاشتراك في أي خدمة مدفوعة. [توثيق GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)، [سير العمل](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

يرفع سير العمل مجلد dist وحده إلى Pages. تستثني قواعد Git المجلدات node_modules وaudit وtest-output وdist. الفهرس العام يحتوي على النص الأصلي اللازم للمقتطفات إلى جانب النص المطبع للبحث. المحتوى كله عام.

## تعديل المحتوى من دون تحرير HTML يدويًا

1. افتح PowerShell داخل مجلد written-library-pages، وشغّل npm.cmd run editor وافتح http://127.0.0.1:8091/tools/editor.html. عند استخدام نسخة مستنسخة حديثًا شغّل npm.cmd ci ثم npm.cmd run build أولًا.
2. داخل مجلد content افتح مجلد المادة مثل d544. من الأداة اختر ملف metadata.json، ثم افتح ملف القسم مثل s567.html. يمكن كتابة النص ولصقه من Word وتنسيق العناوين والقوائم والجداول.
3. عدّل النص ثم اضغط **تنزيل القسم المعدّل**. ارفع الملف إلى المجلد نفسه في GitHub باستخدام **Add file → Upload files**، ووافق على استبدال الملف ذي الاسم نفسه. تجنب الأسماء التي يضيف إليها المتصفح (1).
4. إذا عدّلت العنوان أو المؤلف أو النوع أو ترتيب الأقسام، اضغط **تنزيل بيانات المادة** وارفع metadata.json أيضًا. استخدم **إضافة قسم** لإضافة فصل أو قسم إلى كتاب، وارفع ملفه وبيانات المادة معًا.
5. لإنشاء مادة اختر **مادة جديدة**. تنشئ الأداة أرقامًا للمادة وقسمها وتعرض المجلد المطلوب. نزّل ملف القسم وmetadata.json وارفعهما داخل هذا المجلد. اختر مقالة أو محاضرة أو كتابًا من القائمة.
6. سجّل التعديل في GitHub. سيظهر في الموقع والبحث بعد نجاح Actions. يحتفظ GitHub بتاريخ التعديلات ويمكن استعادة نسخة سابقة منه.

الأداة تعمل محليًا في المتصفح وتحفظ ملفات للتنزيل. يُستخدم HTML معقّم للتنسيق، ثم يتحقق البناء من قواعد الأمان مرة أخرى. يحتفظ التنسيق بالعناوين والفقرات والخط العريض والمائل والجداول والقوائم والحواشي والروابط الداخلية المسموحة. الحد الحالي للقسم في أداة التحرير 128 KiB، ويمكن توزيع النص الطويل على أقسام.

## قراءة الكتب والفهارس

لكل كتاب صفحة تعريف وفهرس مرتب وزر لبدء القراءة. يدعم الفهرس البحث في عناوين الأجزاء وأرقام الصفحات بالأرقام العربية والإنجليزية. عند وجود ترقيم صفحات في النص الأصلي تظهر روابط مباشرة إليه: 120 صفحة في كتاب بين العهدين و180 صفحة في السيرة الذاتية.

صفحة القراءة تعرض جزءًا واحدًا، وفهرسًا جانبيًا يميز الجزء الحالي، وقوائم للانتقال إلى جزء أو صفحة، وأزرار السابق والتالي أعلى النص وأسفله، ومؤشر موضع الجزء وتكبير الخط. يُطوى الفهرس على الهاتف ويمكن فتحه من شريط التنقل. تبقى الروابط الأساسية والفهارس قابلة للاستخدام دون الاعتماد على البحث التفاعلي.

تُحسن تسميات العرض بإزالة نقاط الفهرس وأرقام الصفحات الملحقة بالعناوين. النصوص والبيانات الأصلية وصادرات AI لا تتغير؛ الأجزاء التي لا تملك عنوان فصل موثوقًا تُسمى «الجزء ١» وهكذا، دون اختلاق فصول. أخطاء استخراج PDF أو OCR الموجودة في المصدر تحتاج مراجعة تحريرية مستقلة.

## البحث العربي داخل النص

تُزال علامات التشكيل والتطويل من نسخة الفهرسة، وتتحول أ وإ وآ وٱ إلى ا. تُطبّق العملية نفسها على استعلام البحث. تبقى النسخة المعروضة بكتابتها الأصلية. تستخدم نتائج Pagefind مقتطفات مميزة وروابط إلى الفقرة المطابقة، مع ترشيح المقالات والمحاضرات والكتب.

تعمل القراءة والتنقل عند تعطيل JavaScript. البحث وتغيير حجم الخط يستخدمان JavaScript. التخزين المحلي في المتصفح يحفظ تفضيل حجم الخط فقط.

## ملاحظات المصدر

حُفظ HTML الأقسام الـ661 دون تغيير عند النقل الأول. يتيح npm.cmd run verify:import مقارنة بصمات النقل محليًا قبل تحرير المحتوى. هذا التحقق خاص بالنسخة الأولى، واختبارات النشر العادية تتحقق من المحتوى الحالي بعد تعديلاته.

الكتب الأصلية تشمل نصوص PDF أو OCR سبق استخراجها وقد تحمل أخطاء أو تقسيمات حجمية مقترحة. يعرض الموقع النص الموجود في المصدر، وتبقى مراجعة اللغة وصحة فهرس الفصول مهمة تحريرية. لا تحتوي النسخة الأصلية على جداول أو روابط حواشٍ مهيكلة، لذلك اختُبرت هذه العناصر بعينة اصطناعية منفصلة.
